# OverFive — وب‌سایت لانچر گیمینگ

[English](README.md) | [فارسی](README.fa.md)

**[مشاهده نسخه آنلاین](https://astheking.github.io/OverFive-Website/)** · **[کد پروژه در گیت‌هاب](https://github.com/ASTHEKING/OverFive-Website)**

یک وب‌سایت واکنش‌گرا و دوزبانه که به‌عنوان طرح فرانت‌اند برای لانچر OverFive و سرورهای نقش‌آفرینی FiveM ساخته شده است. این پروژه توسط کارفرمای اولیه راه‌اندازی نشد و اکنون **صرفاً به‌عنوان نمونه‌کار** منتشر شده است؛ این مخزن نماینده یک لانچر رسمی یا سرویس فعال بازی نیست.

## امکانات

- پنج صفحه: خانه، درباره ما، نسخه نمایشی لانچر، سرورها و گالری.
- رابط کاربری فارسی و انگلیسی با پشتیبانی از چینش راست‌به‌چپ در حالت فارسی.
- حالت روشن و تاریک و منوی واکنش‌گرا.
- جست‌وجو، فیلتر و مرتب‌سازی سرورها با استفاده از **داده‌های نمونه محلی**.
- گالری تصاویر با قابلیت نمایش تصویر در اندازه بزرگ و فهرست تصاویر JSON.
- ویدئوی پس‌زمینه بهینه‌شده در صفحه اصلی.
- غیرفعال بودن عمدی دکمه دانلود لانچر در نسخه نمونه‌کار.

## فناوری‌های استفاده‌شده

HTML5 · CSS3 · JavaScript خالص · JSON · Python (ابزار اختیاری ساخت فهرست تصاویر گالری)

این وب‌سایت برای اجرا به فریم‌ورک فرانت‌اند یا مرحله Build نیاز ندارد و نسخه آنلاین آن روی GitHub Pages قرار دارد.

## اجرای پروژه روی کامپیوتر

در پوشه اصلی پروژه (محل قرارگیری فایل `index.html`) دستور زیر را اجرا کنید:

```bash
python -m http.server 8000
```

سپس نشانی **http://localhost:8000/** را در مرورگر باز کنید. اگر دستور `python` در سیستم شما در دسترس نیست، از `python3 -m http.server 8000` استفاده کنید.

پیشنهاد می‌شود پروژه را با سرور محلی اجرا کنید؛ زیرا اطلاعات گالری و سرورها از فایل‌های JSON خوانده می‌شوند.

## افزودن تصویر به گالری

گالری به‌صورت پیش‌فرض سه تصویر دارد و در صورت دسترسی، فهرست `assets/gallery/manifest.json` را می‌خواند. برای افزودن تصویر جدید:

1. تصویر را با یکی از پسوندهای `.jpg`، `.jpeg`، `.png`، `.webp` یا `.gif` در پوشه `assets/gallery/` قرار دهید.
2. در پوشه اصلی پروژه، دستور `python scripts/gen_gallery_manifest.py` را اجرا کنید (یا به‌جای `python` از `python3` استفاده کنید).
3. تصویر جدید و فایل به‌روزشده `assets/gallery/manifest.json` را با هم در گیت‌هاب ثبت کنید.

## محدوده و وضعیت پروژه

این مخزن **فقط کد فرانت‌اند وب‌سایت** را شامل می‌شود. فهرست سرورها از داده‌های نمونه استفاده می‌کند و توضیحات قابلیت‌های لانچر در صفحات، بخشی از طرح اولیه هستند؛ این توضیحات به معنی وجود لانچر عملیاتی، API زنده، سیستم آنتی‌چیت فعال یا فایل نصب قابل دانلود نیستند. دکمه دانلود لانچر غیرفعال است.
